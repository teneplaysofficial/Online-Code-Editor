# Online-Code-Editor

Online code editor using HTML, CSS and JavaScript.

## Features

- Live editing of HTML, CSS, and JavaScript
- Instant preview in the output pane as you type

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/teneplaysofficial/Online-Code-Editor.git
   ```
2. Open the project in VS Code (or your preferred editor).
3. Install the Live Server extension (if using VS Code).
4. Start Live Server (defaults to port **5501**) or simply open `index.html` in your browser.
5. Type your code in the **HTML**, **CSS**, or **JS** panels and see live results on the right.

## Project Structure

- **index.html**: Main interface with three textareas and an output iframe.
- **app.js**: Captures input from the textareas and updates the iframe on keyup.
- **style.css**: Styles to arrange the editor panels and output.
- **.vscode/settings.json**: Sets Live Server port to 5501.
